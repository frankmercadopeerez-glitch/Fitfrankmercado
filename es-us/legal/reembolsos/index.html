Condiciones de compra del plan

Explican cuándo se acepta el pedido, cuándo empieza la entrega y cómo se atienden problemas.

Pago y aceptación

El pago se realiza en dólares por PayPal. El pago solo no inicia el trabajo. El pedido se acepta al verificar el pago y un formulario Formspree completo y elegible.

Entrega

El plan se envía por correo dentro de 24 horas después de aceptar el pedido, en el idioma elegido. Datos incompletos, transacción no verificada o una alerta de seguridad pausan el tiempo.

Si el servicio no puede aceptarse

Si antes de empezar Frank Mercado Fit determina que el caso está fuera de alcance o no puede aceptarse con seguridad, contactará al cliente y devolverá el pago mediante un método disponible, sujeto al proceso del proveedor.

Después de iniciar el trabajo

Como el plan se prepara manualmente para una persona, la cancelación después de iniciar puede no estar disponible salvo cuando la ley obligatoria exija una solución. Esto no elimina derechos irrenunciables.

Problemas de entrega o cobro

Reporta correo faltante, idioma equivocado, cobro duplicado o archivo inutilizable a frankmercadopeerez@gmail.com con el correo del pagador y el ID de transacción. No envíes tarjetas ni contraseñas. Los problemas verificados se corregirán.

Guía gratuita

ShiftStarter es una descarga gratuita separada entregada mediante Payhip.
